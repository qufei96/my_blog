实现方案对比

为"比奇堡热心市民"博客选择最佳实现路径

A

使用现有主题 + 定制修改

选择一个接近经典文学风格的 Hexo 主题（如 NexT、Yelee），进行样式和功能定制

优点

  • 快速上线，1-2 天可完成
  • 社区支持，文档完善
  • 功能插件丰富

缺点

  • 主题结构限制，定制受限
  • 可能需要覆盖大量样式
  • 代码冗余，加载较慢
B

从零开发自定义主题

完全按照经典文学风格设计，手写 EJS/SASS 模板，集成所有功能

优点

  • 完全控制，精确实现设计
  • 代码精简，性能最优
  • 易于后续维护和扩展

缺点

  • 开发时间较长，3-5 天
  • 需要 EJS/SASS 技能
  • 需要自行测试兼容性
C

轻量主题骨架 + 深度定制（推荐）

使用简洁的主题骨架（如 Apollo、Cactus）作为基础，深度定制样式和功能

优点

  • 平衡速度与定制化，2-3 天
  • 主题结构清晰，易于修改
  • 学习成本低

缺点

  • 部分功能仍需自行实现
  • 文档可能不如大主题完善
