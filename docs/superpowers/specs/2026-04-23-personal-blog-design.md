# 个人博客网站设计文档

## 项目概述

为"比奇堡热心市民"创建一个个人博客网站，采用经典文学风格设计，使用 Hexo 静态网站生成器。

### 基本信息

- **项目名称**：比奇堡热心市民博客
- **网站类型**：个人博客
- **内容类型**：混合内容（技术文章、生活随笔、专业领域文章）
- **设计风格**：经典文学风格

---

## 技术选型

| 层级 | 技术 | 说明 |
|------|------|------|
| 静态生成器 | Hexo 7.x | 最新稳定版 |
| 主题基础 | Apollo 主题骨架 | 轻量、结构清晰，作为定制基础 |
| 模板引擎 | EJS | Hexo 默认支持 |
| 样式预处理 | Stylus | 简洁语法，易于定制 |
| 评论系统 | Waline | 支持 Markdown，可自部署 |
| 搜索功能 | hexo-generator-search | 本地搜索 |
| 数据统计 | 百度统计 / Google Analytics | 可选配置 |

### 项目结构

```
blog/
├── source/
│   ├── _posts/           # 博客文章（Markdown）
│   ├── images/           # 文章图片（本地存储）
│   └── about.md          # 关于页面
├── themes/
│   └── citizen/          # 自定义主题
│       ├── layout/       # EJS 模板
│       ├── source/       # 样式、脚本
│       └── _config.yml   # 主题配置
├── _config.yml           # Hexo 主配置
├── _config.citizen.yml   # 主题配置
└── package.json
```

## 页面结构

### 核心页面

| 页面 | 路径 | 功能说明 |
|------|------|----------|
| 首页 | `/` | 文章列表，分页展示（每页 10 篇） |
| 文章详情 | `/posts/:title/` | 正文、评论、分享按钮 |
| 归档 | `/archives/` | 按时间线展示所有文章 |
| 分类 | `/categories/` | 分类列表和分类下文章 |
| 标签 | `/tags/` | 标签云和标签下文章 |
| 关于 | `/about/` | 个人简介 |

### 页面布局

采用经典双栏布局：
- **主内容区**（左侧）：文章列表/正文
- **侧边栏**（右侧）：个人信息、分类、标签

响应式断点：
- **桌面**（> 992px）：双栏布局
- **平板**（768px - 992px）：双栏，侧边栏变窄
- **手机**（< 768px）：单栏，隐藏侧边栏

## 设计规范

### 色彩系统

| 用途 | 色值 | 说明 |
|------|------|------|
| 背景色 | #fffdf7 | 暖色纸张背景 |
| 主文字 | #2c2c2c | 标题、重要文字 |
| 次文字 | #555555 | 正文内容 |
| 辅助色 | #8b8680 | 日期、标签 |
| 边框线 | #c9c4b8 | 分隔线、边框 |
| 链接色 | #a0522d | 超链接（复古棕色） |

### 字体规范

| 用途 | 字体 | 字号 | 行高 |
|------|------|------|------|
| 文章标题 | Georgia / 思源宋体 | 28px | 1.4 |
| 小标题 | Georgia / 思源宋体 | 18px | 1.5 |
| 正文 | Georgia / 思源宋体 | 16px | 1.8 |
| 辅助文字 | Helvetica Neue / Arial | 12px | 1.5 |

### 设计特点

- 暖色纸张背景营造阅读氛围
- 衬线字体突出文学气质
- 细线分隔内容，简洁优雅
- 适当留白，提升阅读舒适度

## 功能模块

### 交互功能

1. **搜索功能**
   - 位置：顶部导航栏搜索图标
   - 交互：点击展开搜索框，本地实时搜索
   - 技术：hexo-generator-search

2. **评论系统**
   - 位置：文章底部
   - 技术：Waline（支持 Markdown）
   - 功能：评论、回复、点赞

3. **分享功能**
   - 位置：文章底部
   - 平台：微博、微信、复制链接
   - 技术：社交分享按钮组件

4. **RSS 订阅**
   - 路径：`/atom.xml`
   - 技术：hexo-generator-feed

5. **返回顶部**
   - 触发：页面滚动超过 300px 显示
   - 交互：点击平滑滚动回顶部

### 数据统计

- 支持百度统计和 Google Analytics
- 在 `_config.citizen.yml` 中配置统计 ID
- 可选开关控制是否启用

---

## 图片管理

采用本地存储方案：
- 图片存放位置：`source/images/`
- 文章引用方式：`{% asset_img filename %}` 或 `![](../images/filename.jpg)`
- 适用范围：预计图片数量 < 200 张
- 建议图片格式：WebP / JPEG（压缩后）

---

## 部署方案

推荐部署平台（任选其一）：
- **GitHub Pages**：免费，适合个人博客
- **Vercel**：自动部署，CDN 加速
- **Netlify**：功能丰富，支持表单

部署流程：
1. 推送代码到 GitHub 仓库
2. 连接部署平台
3. 配置构建命令：`hexo generate`
4. 配置输出目录：`public`
